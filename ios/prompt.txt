Convert the source recipe into a Cookidoo Bridge recipe JSON object conforming to schema version 1.0.

Return ONLY the JSON object. Do not use Markdown fences. Do not include commentary.

Canonical schema:
https://lmguen26.github.io/cookidoo-bridge/schema/recipe.schema.json

Rules:
- `schema_version` must be `1.0`.
- `slug` must be lowercase ASCII kebab-case.
- Prefer metric units and grams where practical.
- Preserve recipe intent while adapting suitable chopping, mixing, heating and sauce steps to Thermomix TM6.
- Keep pan, oven, grill, air-fryer or other external cooking steps when they produce a better result.
- Put machine settings only inside each step's `thermomix` object.
- Use `time_seconds`, `speed`, `temperature_c`, `reverse`, `mode`, and `measuring_cup` only when relevant.
- Do not claim unsupported Cookidoo guided-cooking features.
- Nutrition should be approximate and per serving when reasonably inferable.
- Ingredient objects should separate quantity, unit, ingredient, note and optional group.
- Steps must have sequential integer `order` values starting at 1.
